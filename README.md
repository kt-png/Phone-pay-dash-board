# 📱 PhonePe Transaction Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing PhonePe transaction data using Microsoft Power BI. The objective is to transform raw transaction records into meaningful financial insights through interactive visualizations, KPI tracking, and transaction analysis.

The dashboard provides an overview of transaction activities, spending patterns, payment categories, and financial trends to support better financial understanding and data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall transaction activities.
- Monitor total transaction amounts.
- Understand transaction frequency.
- Identify spending patterns.
- Analyze payment trends over time.
- Evaluate transaction categories.
- Develop an interactive financial analytics dashboard.
